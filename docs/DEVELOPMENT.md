# Development

The project was built as a local desktop solver, layer by layer, with tests before the GUI. The GUI never reimplements ranking.

## 1. Dataset

Original cfreshman Wordle extracts were stored as `data/answers.txt` (2,315) and `data/allowed_guesses.txt` (12,972). Loaders reject case, length, non-alpha, duplicates, and answers missing from the guess list.

## 2. Feedback engine

`FeedbackEngine` implements green-first, then yellow-from-remaining-multiset coloring. Unit tests cover duplicate letters.

## 3. Constraint satisfaction / filtering

A candidate survives if and only if `get_feedback(guess, candidate)` matches every observation. History contradiction detection lives beside the filter, not in the GUI.

## 4. Entropy

Guesses partition remaining answers into at most 243 pattern buckets. Shannon entropy and expected remaining size are computed from those counts.

## 5. Precomputation

A `uint8` matrix of every allowed guess against every answer (codes 0–242) is generated by `scripts/precompute_patterns.py`. Git ignores the ~29 MiB `.npz`; fingerprints bind the file to the word lists.

## 6. Simulation

`simulate()` plays a hidden answer with `maximum_entropy` or `candidate_reduction`. `WordleSimulator` batches answers and groups identical feedback paths when ranking openers.

## 7. Optimization

Optimization in this release means (a) greedy ranking with a cache-backed `bincount`, and (b) path grouping in opener benchmarks. It does not mean lookahead search.

## 8. GUI

CustomTkinter: board, keyboard, assist / solver / simulation tabs, recommendation metrics, compact game statistics, scrollable candidate list. Ranking runs on a worker thread.

## 9. Testing

`pytest` covers word data, feedback, constraints, candidates, entropy, cache, solver, simulator, session, and a headless window smoke test.

## 10. Benchmarking

`find_best_openers.py --top-entropy 5` produced the published JSON. `export_benchmark_artifacts.py` writes CSV tables and SVG figures from that JSON so plots stay aligned with the recorded run.
